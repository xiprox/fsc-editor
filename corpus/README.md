# The corpus

Real FS Copilot profiles, committed, so that the assertions the sweeps make can
run on a fresh clone and in CI — over files people actually wrote rather than
over the handful of shapes somebody thought to invent.

    profiles/   a mirror of a working Definitions folder
    formatted/  what the formatter produces for each of them

## Provenance

Mirrored on **2026-09-20** from two places, because a working Definitions folder
is assembled from two:

|                           | Source                                                         |
| ------------------------- | -------------------------------------------------------------- |
| `profiles/*.yaml`         | `~/dev/fsc/profiles/definitions` — the community profiles      |
| `profiles/modules/*.yaml` | `~/Documents/Definitions/modules` — the shared module profiles |

58 profiles and 11 modules, 2.1 MB.

These files are not covered by this repository's licence.

Refresh with `npm run corpus:sync`, which mirrors both sources — additions,
changes **and removals** — and prints what moved. Override the sources with
`FSCE_CORPUS_PROFILES` and `FSCE_CORPUS_MODULES`.

## The line endings are the point

47 of these are CRLF, 11 are LF, and several are **both within one file**.

That is not untidiness to be cleaned up. `formatProfile` detects a file's line
ending and writes back whichever it found, so a corpus normalised to LF would
exercise the branch nobody has and skip the branch every real user takes.

`.gitattributes` marks `corpus/profiles/**` and `corpus/formatted/**` as
`-text`. Without it git would store LF, hand back CRLF on Windows and LF on a
Linux runner, and the check with the strictest contract in the repository — _a
save never alters what FS Copilot loads_ — would be running against files git
had rewritten.

**Nothing here should be edited by hand.** `profiles/` is a mirror; `formatted/`
is generated.

## formatted/

The formatter's output for every profile, regenerated by
`npm run corpus:golden` and asserted by `scripts/checks/corpus.test.ts`.

A property test over 69 real files fails with _"a400m.yaml: not idempotent"_,
and then somebody opens a two-thousand-line file they did not write and bisects
it by hand. Committing the output instead means a formatter change shows up as
a diff of real output, in the file it happened in, on the line it happened on.

So when the test says the formatter's output changed: if that was intended, run
`npm run corpus:golden` and commit the diff — **after reading it**. The diff is
the whole point of the exercise.

## What runs over it

|                                    |                                                                                    |
| ---------------------------------- | ---------------------------------------------------------------------------------- |
| `npm test`                         | `scripts/checks/corpus.test.ts` — format, grammar, highlight and setter resolution |
| `npm run check:format [folder]`    | The same assertions, plus the report, over a real folder                           |
| `npm run check:grammar [folder]`   | ”                                                                                  |
| `npm run check:highlight [folder]` | ”                                                                                  |
| `npm run check:setters [folder]`   | ”                                                                                  |

The assertions live in `scripts/checks/`, shared by both, so the test and the
sweep cannot form two opinions. What stays in the scripts is what needs a folder
nobody else has: the scope histogram, the words the operator table does not
know, the setters FS Copilot silently refuses, and how often Enter's column
matched.
